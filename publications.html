What happens when code changes?

My research focuses on specific tasks within code review: understanding what a code change does, which parts of a system it affects, and how tools such as change impact analysis and change classification can support developers in these tasks.

Research interests

01

Code review

The setting my work applies to: supporting specific review tasks, such as understanding a change and spotting the follow-up changes it needs.

02

Change impact analysis

Finding which code a change affects, and describing what kind of change it is.

03

LLMs for software engineering

Testing what large language models can really do for code analysis and build failures, with honest datasets and evaluations.

04

Empirical software engineering

Studying software and developers through data, experiments and user studies.
